# FreeAdWorld

FreeAdWorld is a mobile-first global classified advertising marketplace concept.

## Current MVP
- Responsive homepage
- Search and country filtering
- Categories
- Demo advertisements
- Free ad posting in local demo storage
- Ad sharing via native share / clipboard
- No paid APIs required

## Next phase
Connect Supabase for real users, authentication, database, image storage and moderation, then deploy the site on Cloudflare Pages.
